# Robot Audio Bench

English · [日本語](docs/README.ja.md)

A Python CLI for evaluating robot microphones and speech recognition across
speaker angles, distances and noise conditions. Extracted from the Hear-and-Face
benchmark in `pylot_robocup2025`; this repository is open source.
The core tools require no ROS installation, PyLoT workspace, GPU or API key.

## Install and quick start

Requires Python 3.10+. Run these commands from the repository root.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
robot-audio-bench stimuli --output stimuli.csv
python examples/synthetic_demo.py --output results/demo
python -m pytest -q
```

The demo substitutes synthetic tones for speech and exercises the WAV → playlist
→ recording analysis → SNR and summary CSV pipeline. It does not measure speech
recognition accuracy or robot performance. You can also invoke the CLI with
`python -m robot_audio_bench`.

## Measure real recordings

1. Have speakers record the utterances in the CSV generated by `stimuli`.
   Replace `<speaker>` in each `wav` filename with the speaker's name, such as alice.
2. Prepare 16 kHz, mono, signed int16 WAV files and generate a playlist.
3. Place the sound source at each angle and distance, then record it with the robot's microphone.
4. Align the recording to the playlist using the synchronization tone and compare the noise and speech segments.

```bash
robot-audio-bench playlist stimuli.csv --wav-dir recordings --speakers alice --lang en --out-dir playlist
robot-audio-bench analyze --recording rec.wav --playlist playlist/playlist_en.csv \
  --theta-deg 60 --distance-m 1 --noise N0 --lang en --no-asr --out trials.csv
robot-audio-bench summary trials.csv --out-dir summary --no-plot
```

The playlist begins with a 1 kHz, 0.5-second synchronization tone followed by
one second of silence. Each trial's noise segment is silent in the playback WAV:
play environmental noise separately so that it is captured in the recording.
Use `--offset-s` to specify the synchronization offset explicitly.
Trials without a valid SNR have `snr_valid=false` and are not counted as successful
measurements. Calibrate physical sound pressure levels separately; N0/N1/N2 are
condition labels.

## ASR and optional features

Real speech recognition requires your own **whisper.cpp `whisper-cli` build**
and model. The original implementation targets whisper.cpp v1.9.2 JSON full
output. This repository does not download models. Remove `--no-asr` from
`analyze` and supply the executable and model:

```bash
robot-audio-bench analyze --recording rec.wav --playlist playlist/playlist_en.csv \
  --theta-deg 60 --distance-m 1 --noise N0 --lang en \
  --whisper-cli /path/to/whisper-cli --model /path/to/model.bin --out trials.csv
```

`robot_audio_bench/config/dialogue.yaml` and `whisper.yaml` are included in the
installed package, so their default paths do not depend on the working directory.
Override them with `--dialogue-config` (compatibility alias: `--hri-params`) and
`--whisper-yaml`. Their ROS-style configuration wrappers are retained for compatibility.
The initial stimulus generator and prompt selection support two categories:
names and drinks. To evaluate other utterances, supply your own stimulus CSV,
reference text and prompt settings for those categories.

- `noise pink` / `noise babble`: generate pink noise or babble from a local LibriSpeech corpus.
- `directivity`: measure angular response by one-third-octave band; requires NumPy.
- `summary`: report SNR by condition, accuracy with Wilson intervals, WER/CER, ROC and the angle at which accuracy drops.
- Plot generation: `pip install '.[plots]'`. FLAC input: `pip install '.[flac]'`.

Tests cover parsers, argument construction and synthetic data. Real model inference
and microphone performance have not been validated. When using the ASR cache,
choose a new cache directory after changing a model: changes to model contents
at the same path are not reflected in the cache key.
